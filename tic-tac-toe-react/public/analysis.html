    линии второго игрока

    квадрат, который придётся отдать
    Как читать разбор. Ход, закрывший квадрат, даёт право ходить ещё раз - это и есть продолжение. Красная рамка означает, что игрок обязан отдать этот квадрат: у соперника уже собрана цепочка из трёх сторон.

    Управление. Пробел - пуск и пауза, ← → - шаг, Home End - в начало и в конец.
